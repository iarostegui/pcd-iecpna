# Comunicación responsable de seguridad — PCD
El repositorio es visible públicamente mientras su propietario no modifique la configuración. **No** publicar credenciales, PII, coordenadas, hashes de sesiones, datos reales ni vulnerabilidades explotables en issues públicos.
Informar vulnerabilidades al responsable del repositorio por un canal privado acordado o mediante las opciones de reporte privado de GitHub si están habilitadas. No se publica aquí un correo nuevo ni se presume un programa de recompensas.
Antes de cualquier producción: H-40, separación de contraseñas de pruebas, rotación de secretos, protección de backups, acceso a bitácoras y controles de sesión verificados.
