# SDD PCD
`specs/` contiene requisitos vigentes y escenarios verificables por capacidad. Para cambios, crear `changes/YYYY-MM-DD-slug/proposal.md`, `design.md`, `specs/<capacidad>/spec.md` y `tasks.md`; implementar, verificar, consolidar en specs y archivar. Una spec describe QUÉ debe hacer PCD; los documentos `docs/02-diseno` y `docs/03-base-datos` explican CÓMO.
